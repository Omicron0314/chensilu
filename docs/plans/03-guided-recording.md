# Plan 03 — 对话、五栏与即时事实反馈

状态：planned。需求：R01、R02、R03。

## 门禁

Plan 02；D05 保存规则、D06 状态与目标引用口径确认。本阶段只使用 Mock AI；不外发用户内容。

## 目标

把一句对话变成可编辑、可聚合的记录，而非逼用户每日填表。

## 任务

- [ ] 定义引导/抽取契约、Mock 提供商与合成响应。
- [ ] 引导先复述再单点提问；默认一次一问；用户可跳过、结束、今天不想写。
- [ ] 口吻温和/直接；跳过后转自由写，不重复逼问。
- [ ] 展示并编辑五栏，原始对话与整理稿分别可读。
- [ ] 抽取约数时长，保留未知值；用户不用计算，AI 不猜测未提供分钟数。
- [ ] 正反馈作为事实候选由用户确认；支持今天没有，不自动判定进展。
- [ ] 反思仅提供可忽略的引子，不设进度与提醒。
- [ ] 确定性计算保存后事实反馈与引用，无目标时提供有依据的关联或诚实空状态。
- [ ] 校验非法输出/来源/过期版本，取消与失败保留输入。
- [ ] 覆盖中文输入法、长文本、未填字段、关闭 AI、Mock 故障与跳过行为。

## 验收

用户可在 2–3 轮或直接自由写后结束、编辑确认保存；一次点击内见事实反馈。草稿可空、可修改；真实统计不依赖 LLM，Mock 结果明确标识。

## 与周报的衔接

行动与正反馈契约稳定后立即开展 Plan 04，不等对话视觉精修。需要模型质量结论时转入 Plan 05，不以 Mock 表现证明 AI 产品价值。
