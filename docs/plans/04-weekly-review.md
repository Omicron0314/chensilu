# Plan 04 — 周报聚合与 A 档流程

状态：planned。需求：R04。

## 门禁

Plan 02 的记录持久化、Plan 03 的行动/确认/来源契约稳定；D06 多目标聚合口径获批。不要求 Plan 03 界面精修全部完成。

## 目标

从字段直接算出一份可回查周报，尽早让用户跨过完整复盘周期。本阶段 AI 叙述仍为 Mock。

## 任务

- [ ] 领域层实现明确区间与时区，支持过去 N 天、补做、空区间。
- [ ] 按唯一行动聚合已知时长和次数，说明未知值与约数，不重复计时。
- [ ] 按已确认事实聚合正反馈，包含未关联目标组。
- [ ] 保存输入版本与来源快照，所有统计可点击回到记录/行动。
- [ ] Mock 生成有出处的 A 档初稿，校验每条结论引用；无证据不生成泛泛评价。
- [ ] 用户可编辑、确认、查看复盘历史；确认版与 AI 草稿分开。
- [ ] 记录修改/删除后使相关摘要失效或标记复盘过期，不静默覆盖确认版。
- [ ] 对时间边界、重复保存、多目标、未知时长、确认状态与引用失效建立测试。
- [ ] 检查生成输入以字段/精炼摘要为主，不默认读取全部原始文本。

## 验收

使用合成七日日记：统计与手算一致、无需读七篇全文即可理解周报、每个数字与解释结论都有有效来源。补做不受周一等日历限制；无数据为明确空状态。

## 不在范围

月年复盘、B/C 模式、自动推送、复杂长期记忆、真实模型与付费套餐。

## 完成记录

待执行：统计 fixture、实际命令、来源导航与失效验证、风险。
