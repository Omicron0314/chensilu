# Plan 02 — 离线记录与可靠持久化

状态：planned。需求：R01、R06、R07。

## 门禁

Plan 01；D02 存储及加密方向、D05 空字段保存规则获批。

## 目标

先让用户不依赖 AI 地记录、保存和重启恢复。数据安全不等最后发布才加入。

## 任务

- [ ] 定义 Draft/Entry 与版本化 Schema，原文与整理稿分别保留。
- [ ] 使用系统应用数据目录、版本化迁移与事务仓储，注入时钟便于测试。
- [ ] 建立自由写、记录日期、保存状态、历史列表和详情；无目标也可记录。
- [ ] 自动草稿保存、异常退出恢复与关闭策略；明确最后持久化时间和失败反馈。
- [ ] 保存幂等与版本冲突保护，防止重试产生重复记录。
- [ ] 最小一致性数据库备份与失败恢复验证，为后续完整生命周期打基础。
- [ ] 测试离线启动、存储失败、重复保存、重启、迁移失败。
- [ ] 将不属于已获批范围的字段和加密能力标为未实现，不作隐私承诺。

## 验收

合成记录断网下可编辑保存、查看与重启恢复；事务失败不显示已保存；确认的空字段规则不被数据库约束反向阻断。最小备份可恢复，不丢关系数据。

## 交付

真实可用的离线纵向切片、迁移与存储测试、数据路径与恢复说明。Plan 03/04 可以基于稳定记录契约继续。
