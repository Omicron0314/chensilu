# Plan 01 — 桌面骨架与质量基线

状态：planned。需求：R08、R09。

## 门禁

D01 技术栈获批；实际 Linux 环境与必要依赖明确。需要安装系统依赖时先征得同意，不自动更改系统。

## 目标与范围

一个能在 Linux 实际启动的最小桌面应用，建立可信检查命令和安全桥接。尚不接入真实模型、支付或同步。

## 任务

- [ ] 使用获批工具初始化单应用工程、依赖锁文件与最小目录。
- [ ] 记录工具链版本、JS 包管理器与 Rust/原生依赖（如采用 Tauri）。
- [ ] 创建最小窗口、导航与记录/历史/复盘/设置的基础容器；未实现能力标为未实现，不设假完成按钮。
- [ ] 定义命令 DTO、错误码与契约验证方式，建立一个最小安全原生命令。
- [ ] 收紧桌面权限、CSP 和桥接接口，禁止任意 SQL/路径/shell。
- [ ] 建立格式、类型、lint、单元测试与构建命令；首次各运行一次。
- [ ] 建立不上传内容的错误边界与敏感日志脱敏约定。
- [ ] 以最小 CI 验证已存在的检查；原生图形测试无法在 CI 运行时注明手工门禁。
- [ ] 更新 README 的真实环境准备、运行、测试命令。

## 验收

Linux 原生桌面壳能启动并执行类型化桥接；浏览器预览不能替代。检查命令实际通过，未知权限/命令参数被拒绝，仓库没有密钥或开发数据库。

## 不在范围

精修界面、全平台构建矩阵、安装包发布、账号登录、完整数据库与 AI 提供商。
