# Plan 05 — 真实 AI、隐私授权与透明额度

状态：planned。需求：R04、R05、R09。

## 门禁

Plan 03/04 的 Mock 闭环通过；D04 模型部署与允许外发范围、D07 额度与免费循环规则确认。未经授权不得调用真实远程模型处理日记。

## 目标

接入一个获批模型，保持原始记录可靠、调用可控、费用透明。必要商业后端若超出最小范围，先拆出新 ADR/子计划。

## 任务

- [ ] 明确授权文案、数据字段、接收方、保留/训练政策及可撤销范围。
- [ ] 实现一个真实提供商适配器；密钥由原生凭据层或获批后端管理。
- [ ] AI 启用、关闭与队列取消；说明关闭不能撤回已发送的数据。
- [ ] 统一 Schema/证据验证、超时、取消、有限重试、迟到响应与幂等保护。
- [ ] 限制上下文与输出、缓存版本和失效，不发送整库。
- [ ] 实现获批额度来源、消耗单位、余额、失败/取消规则与免费 A 档保障。
- [ ] 区分用户自备 Key 的提供商费用、本地估算、商业服务真实额度，禁止虚假免费承诺。
- [ ] 防止隐藏重复扣费；关闭/耗尽后记录、查看、导出仍可用。
- [ ] 测试日志/错误脱敏、恶意输入、权限拒绝、提供商故障。
- [ ] 用合成数据做一次真实记录到周报的闭环，记录调用量、耗时和成本估算。

## 验收

开启需明确授权，关闭后不发新请求；失败不丢输入。免费方案确能完成一次获批循环，余额清楚可见。真实统计仍由代码计算，模型提供商政策与应用隐私文案一致。

## 风险

模型质量、中文抽取、引用语义与成本须实测。若获批部署方案不可用，标 blocked，不拿 Mock 当真实接入完成。

## 完成记录

待执行：适配器、政策依据、合成调用结果、测试命令、成本与未覆盖项。
