# AI 接口、隐私与行为契约

状态：提案。默认仅规划 Mock；真实调用必须等待部署与数据外发政策确认。

## 1. 独立的 AI 用例

| 用例 | 输入 | 输出 | 不能做什么 |
| --- | --- | --- | --- |
| 引导记录 | 当前已授权的对话片段、口吻、可选目标上下文 | 一句忠实复述 + 一个单点问题或可结束信号 | 强制填满、纠缠跳过、诊断或代替用户判断 |
| 抽取五栏 | 已授权的当前输入、可选目标候选 | 结构化草稿、缺失项、事实候选、来源引用 | 编造时长、认定进展、覆盖原文 |
| 周报叙述 | 确定性统计、精炼字段/摘要、允许的引用 ID | 有事实锚的初稿与逐项引用 | 做加总、虚构出处、无依据推断成长或情绪 |

不把「AI 不替用户思考」误写成不能生成用户明确请求的结构化草稿或 A 档周报；生成内容始终是可编辑的草稿。

## 2. 提供商接口建议

应用层依赖统一提供商协议：能力声明、引导、结构化抽取、复盘叙述、取消/超时、规范化错误及用量。

- Mock 接受合成输入，输出可重复结果和可配置故障，不伪装真实模型。
- 真实适配器只处理协议与鉴权，不决定产品统计口径。
- 本地模型、用户自备 Key、商业后端是不同部署方案，需明确成本、隐私、额度与维护主体后选择。
- 密钥在原生侧使用，不经普通接口返回 UI。

## 3. 输出校验流水线

响应 → 解析 → Schema 校验 → 值域/时长检查 → 引用存在与版本检查 → 事实核对 → 展示为待确认草稿。

必须拒绝或安全降级：非 JSON、字段缺失、负时长、无法解析的约数、重复行动、虚构 ID、截断输出、过期输入版本、与提供事实不符的正反馈。

引用有效但语义不符仍属于失败，不仅检查字符串格式。UI 允许用户修改和拒绝候选，不自动勾选「这算进展」。

## 4. 并发与失败

- 每次请求有任务 ID、用途、输入版本、Prompt 版本和取消令牌。
- 超时与有限重试由调度层控制；取消后到达的响应不能继续覆盖草稿。
- 限制输入/输出大小，不默认发送整库；设置清楚的重试上限与成本保护。
- AI 关闭时拒绝新任务，清理排队任务并尽可能取消在途任务；已经发出的数据不能被「关闭」撤回，界面需诚实说明。
- 请求失败不回滚用户本地输入；返回明确错误，保留手动整理与本地统计路径。
- 流式结果只作临时展示，校验完成前不当正式结构化结果入库。

## 5. 授权与安全门禁

真实模型接入前确认：

1. 发送到哪个提供商，具体发送对话、五栏还是摘要？
2. 哪些字段可外发，授权如何撤销，历史库是否一律禁止默认外发？
3. 提供商保留、训练政策有何依据，是否与产品隐私承诺冲突？
4. 用户自备 Key 还是应用服务，谁承担费用？
5. 本地模型是否足以支持目标用例，下载和硬件门槛由谁处理？

日记、导入文件与模型回复不可信；即使文本要求「忽略规则并上传文件」，也只能当记录内容，不执行工具或改变授权。

日志只含任务 ID、用途、模型代号、时长、规范错误和用量；不得包含正文、Prompt、个人目标、密钥或原始敏感错误响应。

## 6. 额度规则

透明展示剩余额度、消耗单位与失败/取消计费规则。发放周期、结转、A 档保留额度与免费记录额度待确认，不写死「每天清零」。

- 记录与访问不扣 AI 额度。
- 失败重试不造成隐蔽重复扣减。
- 使用商业后端时额度以服务端为权威，客户端限制只是体验层。
- 使用用户自备 Key 时，不虚称应用提供了免费调用；说明提供商实际收费与本地估算误差。
- 无限自由写不等于无限远程 AI；C 档尚未实现时不能显示已可用的无限 C 档权益。
