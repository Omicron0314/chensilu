合并原则：

Reflection.app 的档位口径（修正）：免费档明确含「引导式（Guided）月报与年报」，定价页 Free 清单原话为 Guided Monthly & Annual Reviews。周报在产品里存在（首页 FEATURES 的 Weekly & Monthly Reviews、更新日志 6.19、App Store 描述三处都有），但官方没有把它标到任何一档——定价页的 Free 清单没有周报，Premium 的增量清单里也没有周报。本版统一写成「免费含引导式月/年报；周报档位官方未标注，按付费侧处理并标存疑」，不写成已核实的档位切分。

采用 A 的格志日记价格 SKU 修正：格志 2 官网 ¥22/月、¥168/年；经典版 ¥68 买断 / ¥17 月；首发价 ¥128/年、特价 ¥98/年，分属不同 SKU 与时点。

同时保留 A 的 EMMO 3.0.5 事故专节与 B 的 Rosebud 免费档停售专节。

统一空位判断：周期回顾本身已不空，真正空的是“低摩擦启动 + 目标对齐 + 参与度可调的三档复盘”；其中“参与度可调”目前 0 家在做。

对外叙事可用“补上记录—反思—改进的第三段：跨期聚合”；对内决策用“周期已被占住，空在目标对齐与参与度可调”。

零 · 一页纸结论
分析目的： 验证三件事——低门槛记录是否成立、周期回顾是否带来正反馈、用户是否愿意付费。

竞品清单：
8 主力：Rosebud、Reflection.app、Day One、心光、EMMO、flomo、格志日记、吾记；
1 开源参照：白守 Next；
4 补充观察：Moo / 墨记 / 时光序 / 心岛；
海外补充：Mindsera、Apple 日记；
4 类替代：通用大模型、备忘录与微信、纸笔、Notion / Obsidian。

关键发现：

周期回顾不再是空白，但免费给到的是“引导式”，不是“自动生成”。
Reflection.app 免费档含引导式月报与年报（定价页 Free 清单原文 Guided Monthly & Annual Reviews）；周报在产品里存在，官方未标注档位，按付费侧处理（存疑）。Mindsera 的 Story View 已做到日/周/月/年自动摘要，白守到年鉴，格志有日/周/月/年四模板但纯手动。
→ 结论：周期能力已被占住，真正空的是“目标对齐”“参与度可调”，以及“把一次完整循环免费给到”。

没有任何一家同时做齐「对话引导 + 目标对齐 + 周/月/年全链 + 参与度可调」。
Rosebud 有对话与目标，周期止步周报；Reflection 周期最全，无目标对齐；格志四维手动、无 AI；心光有来信/月刊，无目标；白守最深但要自配 API Key。四项齐备者：0 家。

「复盘参与度可调」是彻底空白。
竞品全是固定形态：全自动生成（Rosebud 周报、Reflection 自动周/月报、心光来信）、纯浏览（格志四视图、吾记时光隧道、Day One 往年今日）、纯手动（flomo 外的笔记类）。
产品定义里的“AI 初稿 / AI 列方向 / 自由思考”三档，0 家在做，且它同时是成本旋钮。

结构化是稀缺的，而且稀缺在产出端——记完之后拿到的那一条。
多数产品的结构化停在输入端（模板、提问库、AI 对话），一旦记完就退回自由文本。产出物本身带固定栏目的只有四家：格志（九宫格）、Five Minute Journal（早晚固定空位）、Moo 日记（时间—事件—情绪—细节四步）、Reflection.app（Highlights / Lowlights / Free Writes 三栏）。
这四家的字段清一色服务情绪与感恩：mood、gratitude、highlights、lowlights、情绪百分比、心情红绿灯。
→ 结论：没有一家有「今天为目标做了什么」「花了多少时间」这一类服务目标与投入的字段。「时间投入」在日记品类里 0 家，只存在于时间记录与习惯追踪产品（Pomodoro Diary、爱时间）。详见 9.2。

国内付费习惯已被验证：38–128 元/年跑得通。
吾记 ¥38/年、EMMO ¥43/年档、格志 2 ¥168/年、flomo PRO ¥99/年。付费抵触高度集中在“锁用户自己的数据”。

替代方案的失败点一致：没有长期记忆、不能自动跨周月聚合、每次都要重新交代背景。
通用大模型与备忘录/微信都倒在这里。白守用“本地 + 层级总结”补上前两点，代价是自配 API Key。

两个关键反面教材：

EMMO 3.0.5：同时加社交、游戏化、付费限制，引发集中差评，官方道歉并十项回滚。

Rosebud 免费档停售：长期记忆系统成本过高，2026-09-30 停免费档。
→ 一个说明“产品不能变重”，一个说明“长期记忆是付费点，也是成本黑洞”。

对我们的启示：

做： 对话引导（一次一问、可跳过）、自动结构化草稿、与目标挂钩的即时正反馈、复盘参与度三档、可关闭 AI、自己的数据永久免费可看可导出、MVP 阶段就做自动草稿与备份、分层记忆、产出端固定五栏（目标—状态—投入—正反馈—反思，其中三栏可被机器聚合）。

不做： 心理诊断、社交社区、游戏化、强制 AI、把用户已有数据当付费墙、复杂编辑器、All-in-one。

待验证： 用户是否愿意让 AI 读日记？周报打开率？付费点落在 AI 深度服务还是同步与空间？¥10–30/月与 99 元/年哪档更成立？分层记忆质量与成本。

MVP 建议（P0）：
一次一问的对话记录（3–5 轮、可跳过）→ 自动结构化草稿，落成固定五栏（目标 / 状态 / 时间投入的具体行动 / 正反馈 / 反思，必填只需两项）→ 记录后与目标挂钩的即时正反馈 → 周复盘「AI 初稿 + 用户确认」一档，结论从可聚合的三栏直接算出 → 免费额度透明 + 数据导出删除 → 自动草稿与崩溃恢复。
先用 Concierge MVP（微信群 + 人工/半自动周报，20–50 人跑 4 周）验证留存与付费意愿，再开发。

排期优先级（工作流要求正面回答「先做对话引导还是先做周报」）：先对话引导，周报同周跟上，中间不留缓冲。判据是当天能验证的可以并行做，只有日历能验证的必须最早开始。详见 11.0。

差异化暂定：
低摩擦的对话启动 + 与周月目标挂钩的记录 + 认知负荷可调的三档周期复盘 + 产出端的固定五栏（目标—状态—投入—正反馈—反思）。
对外口径：不是“AI 帮你写日记”，而是“每天三分钟对话，把今天和你的长期目标连起来”。
划界句：判断与反思始终属于使用者本人，AI 只做启发与补全。
四条差异化里最硬的一条是“投入”这一栏：它是唯一能把日记变成可统计的投入账本的字段，且日记品类里 0 家在做。

三 · 竞品速览（合并版）
3.1 国内组
心光（Lifelight）

定位：AI 生活记录伴侣。随手记（文字/照片/录音）+ AI 朋友回应 + 每周 AI 来信 + 记忆藤蔓 + 自我洞察报告；周刊 + 月刊 + 年度翻页书 + 那年今日。

AI 角色：陪伴型，非追问式引导。目标对齐：无。复盘：固定形态，无参与度选择。

价格：月 ¥18 / 年 ¥98；另有 ¥1,298 买断记录，与第三方 ¥198 出入大，存疑。

好评：陪伴感、AI 总结回顾、录音体验、每周来信。

差评：闪退/耗电、付费墙（“看旧日记要会员”）、AI 来信胡说、数据丢失、要通讯录权限。

可借鉴：记录后自动补元数据；每周来信把复盘触发成本降到零；长期记忆 + 周来信的“被看见”设计。

EMMO 日记

定位：可以画表情的心情日记。AI 角色：Pal（提问 + 偶发评论），非对话式引导。

数据：苹果中国区 4.8 分 / 26.7 万评分。

价格：免费 + 订阅/买断。

关键事件：2026-09-29 发布 3.0.5，加社交、游戏化、付费限制，引发集中差评，官方道歉并十项回滚。

可借鉴（反面）：一个版本别同时动社交、游戏化、付费墙；AI 要可关闭、要克制；产品不能变重。

格志日记（Grid Diary）

定位：九宫格提问式日记，日/周/月/年四模板。无 AI，全手动。

数据：苹果中国区 4.7 分 / 约 0.53 万评分。

价格：

格志日记 2：官网 ¥22/月、¥168/年（含 3 天试用）。

经典版：¥68 一次性买断 / ¥17 每月；2013 首发，2019-10 后停更。

首发价：¥128/年，首发特价 ¥98/年。

引用必须写明版本与时点。

可借鉴：“提问引导”被验证能降低启动门槛；日周月年层级设计值得沿用，只是要自动化。

我们的差异：把静态问题库升级为 AI 动态提问 + 自动结构化 + 自动复盘初稿。

flomo 浮墨

定位：极简卡片笔记，“持续不断记录，意义自然浮现”。

AI：分析型——相关笔记、AI 洞察、找一找、随机漫步、Agent 读全库、AI 记忆档案。

数据：苹果中国区 4.9 分 / 5.25 万评分。

价格：PRO ¥15/月、¥99/年；MAX ¥39/月、¥299/年。

好评：极简记录、回顾设计好、不卖数据无广告、“Agent 记得我说过什么”。

差评：“我有四千条笔记，可是我不会用 Agent”“输入时很开心，整理时体验稀碎”。

可借鉴：长期上下文是用户真正愿意付钱的东西；记录-回顾闭环完成度；干净商业模式。

吾记

定位：大众时间轴日记。

数据：苹果中国区 4.9 分 / 37.6 万评分。

功能：时间轴、信纸、照片视频、密码/指纹、导出 Word、每日提醒、过客社区；v6.0 新增“时光隧道”。

AI：无。价格：¥8/月、¥38/年。

可借鉴：38 元/年价格锚点；“时光隧道”式回看证明用户对周期回看有需求，只是缺自动生成。

3.2 海外组
Rosebud

定位：会追问的 AI 日记教练。对话追问 + 长期记忆 + 意图设定 + 周报（含 Cast of Characters）+ Ask Rosebud + 语音。

价格：免费档 2026-09-30 停售；Bloom $12.99/月，年付 $107.99。

付费墙：长期记忆 / Ask / 语音全在付费档。

好评：“像是和一个记性好得惊人的人说话”、追问具体、语音懂我、周报跨期综合质量高。

差评：“每个按钮都是付费墙”“一周之后它变得苍白而单薄”、隐性额度、循环健忘。

可借鉴：周报的“Cast of Characters”换成目标网络就是沉思路要的东西；同时是“免费档 + 长期记忆”成本失控的活案例。

Reflection.app

定位：引导式反思日记 + AI 教练。

功能：写作中实时追问、100+ 引导 journey、语音转写、Insights、MCP、从 Day One 导入。

回顾周期：
免费档：引导式（Guided）月报 + 年报——定价页 Free 清单原文。
周报：存在于产品（首页 FEATURES「Weekly & Monthly Reviews — Auto-magical recaps」、更新日志 6.19、App Store 描述），但官方未把它标到任何一档；定价页 Free 清单与 Premium 增量清单里都没有周报。按付费侧处理，存疑。
无目标对齐；参与度固定。

价格：Free Forever；Premium $8/月，年付折合 $5.75/月。

隐私：AES-256 + TLS；明确不用于训练（免费档同样适用）；可一键关闭全部 AI。

好评：“Generous free offering”、AI 追问“真的有用且不无限啰嗦”、同步稳。

差评：“全都藏在付费墙后”、Web 端崩溃、同步/登录失败。

可借鉴：周期能力可以免费给（引导月报+年报进免费档）；付费点放在“无限 AI + 同步 + 导出”。

Day One

定位：记录一切的传统日记。默认端到端加密。

数据：美国区 4.83 分 / 11.8 万评分。

价格：Basic $0（限 1 设备）/ Silver $49.99/年 / Gold $74.99/年；无月付。

AI：只到单篇（摘要/标题/配图），无周期生成。

可借鉴：“往年今日”养回访习惯；端到端加密默认全档，是信任最低配置。

白守 Next（开源参照，非市场竞品）

形态：AGPLv3 开源；Electron 桌面 + Expo 移动；本地 Markdown/SQLite，数据不上传；模型可切换；自配 API Key。

核心机制：层级总结链——日记→周记→月报→季报→年鉴，下层产物作为上层输入；RAG 记忆。

数据：GitHub（2026-10-07）93 stars / 9 forks / 15 open issues / 最近提交 2026-10-01 / 最新 release v1.2.24；issue #59 同步报错仍 open。

判断：不是市场竞品，是架构参照。它的层级总结是解决“长期记忆成本黑洞”的现成机制；门槛反证“零配置”是入场券；同步 bug 提示同步是坑。

注意：未读源码、未实跑，总结质量属方向性判断（存疑）。

Mindsera / Apple 日记

Mindsera：AI 教练 + 52 个思维框架 + 周报邮件；免费档 Curious 不含任何 AI，Genius $14.99/月（年付 $129，第三方有标 $99 与 $94.99 的，以官网为准）。获客靠应用商店推荐（iOS 4.9、49 国推荐）、Product Hunt、媒体报道与治疗师推荐，另有自营的对比文与榜单文。用户量 80k+ / 168 国 / 300M+ 词为厂商自述，无第三方核验；无公开融资记录，自述独立运营、靠用户付费。验证“框架化反思”与免费额度策略可行。

Apple 日记：系统级免费，照片/位置智能建议，无 AI 复盘。免费替代压力上限：只解决“记”，不解决“复盘”。

六 · 两个关键事件专节
6.1 EMMO 3.0.5 事件复盘
时间线： 2026-09-29 发布 3.0.5（对外称“EMMO 2 全新升级”）→ 苹果中国区最新 50 条评论中约 17 条为 1–2 星 → 官方发布公开道歉并列出十项回滚。

这个版本加了什么： EMMO Pal（皮肤与饰品、家园、互动来信与串门）、花园（种花浇水）、世界与商店（签到、任务奖励）、焕新日记体验、心情图表与月度回顾、更多个性化设置。

官方道歉信节选：

“对不起，这次更新，让很多喜欢 EMMO 的朋友失望了。页面变复杂了，功能限制多了，社交的部分太重了。我们忙着增加功能，却没有照顾好大家最在意的感受：能不能轻松、安心地记录生活。另外，因为服务遭到攻击，我们不得不增加登录要求。部分用户也遇到了会员权益无法正常使用的问题。”

官方回滚十条： 页面更简洁 / 支持无社交模式 / 更多功能免费 / 开放日记搜索 / 更多小组件 / 列表更好用 / 备份更无感 / 支持禁用同步 / 更多导出方式 / 拍立得照片墙。

我们读出的四条：

变重会反噬。 社交 + 游戏化 + 付费限制同时上线，是最贵的一次翻车。沉思路的“不做”清单因此从判断升级为有实证。

把安全成本转成用户体验成本，会被读成另一回事。 “服务遭攻击所以加登录要求”在技术上是合理反应，用户读到的是“你要收我的数据了”。安全加固要配一句能被理解的解释。

会员权益失效比功能少更伤。 老用户最不能接受的是花过钱的服务突然不能用。权益校验与同步属于 P0，不属 P1。

轻量纯粹是留存的基本盘。 官方肯公开道歉并十项回滚，说明“简单、暖心、不用学”这批用户是主力。沉思路的定位与这批人的偏好同向。

6.2 Rosebud 免费档停售
事件： Rosebud 帮助中心原文——“Because this advanced system requires significantly more resources to run, we are unfortunately unable to sustainably offer a free tier moving forward. Effective September 30, 2026, the Rosebud free plan will be retired.” 官方给出的原因：新版长期记忆系统消耗资源过大。同时承诺“你的记录永远属于你”，可随时导出，并对免费用户给过渡优惠。

三层含义：

验证价值： 长期记忆是用户愿意付费的东西（flomo 的 Agent、Rosebud 的 memory、用户原话“记性好得惊人”三重印证）。

警告成本： 长期记忆也是成本黑洞，能把 10 万+ 用户产品的免费档直接压死。对我们的直接含义：产品定义里的“摘要压缩、缓存、按需调用”从优化项升级为生存项；“三档参与度”同时也是成本旋钮（AI 初稿贵 → 给方向中 → 自由+提醒便宜）；白守的“日记→周→月→季→年鉴、下层产物喂上层”是现成的成本解法。

让出空位： Rosebud 把“免费也能有长期记忆/周期回顾”这个位置空了出来。谁能用低成本分层记忆把这个位置接住（免费给到“一次完整循环”），谁就拿到一批被赶出来的用户。注意：官网首页仍在写 “Rosebud is free to use”，说明营销页未同步，以帮助中心为准。

7.1 候选轴交叉验证（工作流要求给 3 组轴，上一版只给了 1 组）

现用轴是「启动门槛 × 闭环强度」。这张轴有个自己承认的弱点：闭环强度是自定判据（「有没有自动生成的周期产物」），不是行业通用轴。补两组候选轴做交叉验证，两组都遵守选轴铁律——挑「我站在某一边就是优势」的维度。

候选轴一：成长导向 ↔ 情绪疗愈导向
- 我们站：成长导向。
- 对照证据：心光、EMMO、Mindsera 的聚合对象是 mood、情绪百分比、心情分布；我们的聚合对象是目标与时间投入。这正好是沉思路对心光 / EMMO 最真实的分界。
- 判定：成立，且比闭环强度更锋利，因为它指向的是需求本身而非功能完成度。

候选轴二：对话式交互 ↔ 模板式写作
- 我们站：对话式。
- 对照证据：格志与 Five Minute Journal 是模板填空；我们是 AI 主动一次一问。
- 判定：**部分成立。** 这组能拉开与模板派的差距，但 Rosebud 也在对话侧，Mindsera 兼有对话与模板两种入口，所以这组轴对 Rosebud 无效，不能单独拿来当差异化。

三组轴交叉后的修正：
- 三组指向交集合在一格：**成长导向 × 低启动门槛**。
- 「对话式」这一格已经有 Rosebud 站着了，所以对外不能靠「我们是对话式」讲差异化，要靠「成长导向 + 参与度可调 + 带量化字段」讲。
- 这条修正比原图更有用：它告诉我们哪一格是空的（成长导向 × 低门槛），哪一格只是看着空（对话式）。

八 · 关键发现（事实 → 意味着 → 因此）
事实： 国内日记 App 头部评分都在 4.7–4.9（吾记 37.6 万评分、EMMO 26.7 万评分），“写”的门槛已被心情标签、提问、语音解决。
意味着： 单纯“AI 帮你写日记”不再是差异化。
因此我们： 不做又一个心情日记，把注下在记录之后的反思与改进。

事实： 周期回顾已被多家做开：Reflection.app（免费档含引导式月/年报）、Mindsera（Story View 含日/周/月/年自动摘要）、白守到年鉴、Rosebud 到周加年度 Wrapped。
意味着： 周期能力本身不再是我们独占的空位，“低门槛”与“目标对齐”才是。
因此我们： 差异化重新定位为“低摩擦启动 + 目标对齐 + 参与度可调的三档复盘”，而不是“我们有周月年”。

事实： 目标对齐在现有产品中近乎空白——Rosebud 有意图设定但周期止步周报，时光序有目标与打卡但日记是附属，格志靠手动模板，心光、EMMO、flomo、吾记都没有。
意味着： “每日记录 ↔ 周月目标 ↔ 周期复盘”三者的联动是最大机会点。
因此我们： 把目标对齐做成核心差异化，并保留无目标时的轻量横向关联兜底。

事实： 付费抵触高度集中在“我的数据被锁”（心光看旧日记要会员、EMMO 照片数量收费），而用户愿为云同步、空间、AI 深度付费（38–128 元/年已验证）。
意味着： 付费墙的位置决定口碑。
因此我们： 记录、查看、导出永久免费；付费买 AI 深度服务。

事实： 稳定性是生死线——闪退、丢数据、同步失败是差评第二大来源；EMMO 事故中会员权益失效直接引爆信任危机。
意味着： 记录工具的数据安全与权益可靠，权重高于功能丰富度。
因此我们： MVP 就做自动草稿、崩溃恢复、备份导出，宁可少一个功能。

事实： EMMO 3.0.5 同时加社交、游戏化、付费限制，引发集中差评。
意味着： 产品变重会反噬，且用户会怀念“简单暖心的旧版本”。
因此我们： 不加社区、不加游戏化、不加广告，保持轻量克制。

事实： Rosebud 因长期记忆系统成本过高停掉免费档。
意味着： 长期记忆既是付费点，也是成本黑洞。
因此我们： 分层记忆（日→周→月→目标）+ 摘要压缩/缓存/按需调用作为架构前提；三档参与度同时作为成本旋钮。

事实： AI 的容忍度取决于可控性——用户明确要求可跳过、可关闭，并反感“很人机”“瞎评论”。
意味着： AI 质量不是模型强弱问题，是分寸问题。
因此我们： 一次一问、可跳过、可关闭，保留自由写模式，语气克制不说教。

九 · Benchmarking 对标表（对标对象：Rosebud、Mindsera）

说明：这一节不是 SWOT 自我安慰，是用行业最佳实践照镜子。维度由对手定，先拆对方公开的方法论与产品标准，再逐项对照我方设计。标注体系见第十三节：已核实事实 / 推断 / 待验证假设。

9.0 先拆对方的标准

Rosebud（治疗师共设计路线）
公开方法论：therapist-backed。具名框架有 CBT（Reframing Negative Thoughts）、Gratitude、ACT（Acceptance and Commitment）、IFS（与 IFS 治疗师 David Coates 共创）。来源：help.rosebud.app/daily-journaling/guided-journals；rosebud.app/blog 的 IFS 专文。
引导节奏：日常打卡是三问变体（Rose/Bud/Thorn）；Dig Deeper 分两种模式——Interactive 模式给「一个观点 + 一个单点追问」，Focused 模式一次给 3 个问题。来源：help.rosebud.app/tools-for-growth/dig-deeper。
未公开：每轮问几个问题、一轮约几轮对话的量化；追问是否按「事件—感受—反思—行动」组织。
付费墙（2026-10）：免费档 2026-09-30 停售；Bloom $12.99/月 或 $107.99/年；Thrive 2x / 5x 两档官网无权益说明。长期记忆为 Bloom 独占。

Mindsera（框架库路线）
公开方法论：52 个思维框架，官网分类加总准确——Journaling 6 + Productivity 13 + Wellness 9 + Decision Making 9 + Problem Solving 7 + Business 8 = 52。含 First Principles、Inversion、Anti-Goals、GROW、Ikigai、Regret Minimization、Second-Order Thinking、5 Whys、CBT 重构。来源：mindsera.com/frameworks。
公开的评估维度：情绪用 Plutchik 轮、人格用 Big Five、跨条目用 Recurring Topics。评分阈值与算法不公开。来源：help.mindsera.com/editor/entry-analysis。
记录入口：Minimal journal / Voice Mode / Call Mode（通话式语音）/ Scan Physical Journal / Morning-Evening Rituals / 52+ 框架模板。框架模式是「a series of questions」逐题填答，不是对话。
AI 三个角色并存：教练（Call Mode）、分析者（Entry Analysis）、评审（Minds 边栏批注）。Go Deeper 明示「不给答案、不总结」，只抛思考题。
付费墙：免费档 Curious 不含任何 AI 功能；Genius $14.99/月 或 $129/年。来源：help.mindsera.com/comparison/free-plan-vs-paid-plan。

三条结论
一、结构化是稀缺的，而且稀缺在产出端。多数产品的结构化停在输入端（模板、提问库、AI 对话），一旦记完就退回自由文本，靠 AI 外挂几个分析字段。真正让产出物本身带固定栏目的只有四家：格志、Five Minute Journal、Moo 日记、Reflection.app。
二、现有的结构化清一色服务情绪与感恩。字段是 mood、gratitude、highlights、lowlights、情绪百分比、心情红绿灯。没有一家有「今天为目标做了什么」或「花了多少时间」这一类服务目标与投入的字段。
三、「时间投入」这个字段在日记品类里 0 家在做。它只出现在时间记录与习惯追踪产品：Pomodoro Diary 官方明言记录 goal completion 与「the time invested in achieving those goals」；国内爱时间是柳比歇夫式记录（类别 + 时长 + 备注，自动生成日 / 周 / 月时间轴）；时光序有阅读计时与番茄专注，但没有并进日记字段。把时间投入并进每日日记的固定栏目，是一次跨品类的借位——好处是无人竞争，代价是没有可抄的参照，口径要自己定。

9.2.1 我方五字段：目标 — 状态 — 时间投入的具体行动 — 正反馈 — 反思

判据先说清。结构化的真正价值不在「心理上安全稳定」（这是主观收益，无法验收），而在**字段能被机器聚合**：复盘时不必读七篇日记，靠字段直接出统计，复盘成本才降下来。所以每个字段都要问一句——周复盘时它能被算什么。

字段	复盘时能算什么	可否聚合	建议
目标	本周注意力落在哪几个目标上；哪些目标一次没被提及	可聚合	保留。无目标日可空，退回横向关联兜底

四条设计口径
一、必填与可空分开。必填只有「时间投入的具体行动」与「正反馈」两项；目标、状态、反思都可空。理由是结构化一旦变成每日门槛，就与降低启动成本的产品目标反向。
二、时间不能靠用户填。断点一本身就是「面对空白页的决策成本」，再让用户算时间等于加回一道门槛。做法是 AI 在对话里问一句「今天大概花了多久」，用户随口给约数，系统填进去，用户只确认；没给就留空，不卡保存。
三、正反馈不由 AI 写。AI 只把事实摆出来（「你今天为 X 做了 25 分钟，这是本周第 3 次」），用户勾一下是否算进展。差评里「AI 味重」「瞎评论」集中在 AI 主动评价上，这条要避开，它与风险边界里的「反馈基于事实」是同一条约束。
四、给这套结构一个可引用的名字。这五个字段与教练圈的 GROW 模型同构：G 目标 → R 现状 → O 方案 → W 行动承诺；复盘模板圈里，Notion 的周复盘（Wins / Challenges / Insights / Next Week）与 OKR 周报（目标 O / KR / 进度 / 状态 / 原因及改进）用的是同一个骨架。挂上去正好补上 9.1 指出的短板（我方缺一个能被引用的方法论骨架）。对外表述建议：以 GROW 骨架把每日记录落成五栏，让目标与投入一一对应。

顶层规则（由五字段收出的一条，可用于挡掉后续新增字段）：
量化发生过的事（投入、进展），不量化感受到的事（情绪、反思）。这条一次解决三个问题：字段的可聚合性、情绪量化的伦理风险、用户的心理负担。

补记一（正反馈的第二重价值）：它不只是周报原料，还是可被反复消费的内容库——投入的数字一次性，正反馈的条目可重读，记一次被读多次。竞品的回忆功能全按日历轴（Day One 往年今日、吾记时光隧道、心光那年今日），没有一家按语义轴检索好事，因为它们的条目里没有这个字段。字段先有，检索才可能。

补记二（反思的定位）：反思是五栏里唯一不该被结构化的字段。它的目的是把体验变成经验，在日尺度上做局部优化；一旦给它固定问题就变成作业，撞上形式化与赶走想倾诉者两条风险。它不进统计口径，但进模式识别（周报可说「你这周三次提到同一件困扰」），且必须能回链原文——这个机制 Mindsera 的 Recurring Topics 已经在做。

补记三（日尺度是关键）：局部优化把复盘的意义从宏大成长降回「今天比昨天好一点」。别人的最小循环是周报（Rosebud）或月报（Reflection），我们的最小循环是一天。这一句比「我们有周月年」更能打动目标用户。

与北极星指标的关系：五字段里有三个可聚合（目标、时间投入、正反馈），正好对上北极星里的「周报」——周报的价值就是从这三栏直接算出来，而不是把七篇日记重读一遍。这是 11.2 那条验收标准「读一份周报不需要读七篇日记」的实现路径。

9.3 前十个维度照出来的三条

一、对位或无人对位的三处：一次一问的主动引导（与 Rosebud Interactive 同级）、目标对齐（唯一找不到对位）、参与度可调（0 家）。这三处是我方站得住的地方。
二、需要重新论证的两处：「AI 主动开场」在两家对标对象身上都查不到先例，属于无人验证的区间，要当假设而不是当优势；「免费给到一次完整循环」成本压力最大，必须先算成本再定额度。
三、落后或需要补短的一处：我方没有一个能被引用的方法论名字，而两家的深度都挂在一个具名框架上。这属于可以低成本补上的短板。

十一 · 对沉思路的直接含义

11.0 先做哪个：对话引导还是周报（工作流要求正面回答，不能两个都放 P0）

先给结论：这不是二选一，但若必须排先后，先对话引导；周报必须在同一周内跟上，两者之间不留缓冲。

理由不是「哪个更重要」，是两者的验证周期不同：
- 「AI 对话能否降低门槛」当天就能验证（首次记录完成率、对话→保存转化率）。
- 「周期回顾是否带来正反馈」只能靠日历时间验证，最少要跨过一个完整的周。产品化方案里那句「留存需要日历时间，压缩不了」是同一个道理。
- 因此排期原则是：验证周期长的事情先开始跑。周报不必先做完，但要尽早让用户拥有第一份周报，否则内测结束时拿不到「周报有没有用」的答案。
- 还有一条硬依赖：对话引导是周报的原料，没有记录就没有周报。依赖链上对话引导确实在前。

落到排期：
1. 第 1 周：对话记录跑通（一次一问、可跳过、能存），同步做出「周报从字段聚合」的最小版本——不需要好看，只需要能出数。
2. 第 2 周：让内测用户跨过一个完整的周，开始收周报查看率。
3. 第 3–4 周：按数据决定加厚哪一端——周报没人看，去查记录质量；记录完成率低，去查提问节奏。

一句话判据（可复用到任何功能排序）：当天能验证的可以并行做，只有日历能验证的必须最早开始。

11.1 差异化（合并收敛版）
低摩擦的对话启动 + 与目标挂钩的记录 + 认知负荷可调的三档周期复盘。

四条对照的证据：

比心情日记（心光 / EMMO）多一层反思与改进：记录 → 结构化 → 目标关联 → 周期复盘 → 新目标。

比引导式日记（格志）多一个 AI 引擎：动态提问、自动整理、自动初稿，把四维度的“手动浏览”变成“自动生成 + 可调参与度”。

比笔记工具（flomo）与周期产品（Reflection.app）多一个成长场景与目标挂钩：Reflection 有周月年但没有目标对齐。

第四条对照（产出端，原稿漏掉的一条）：现有产品的结构化全停在输入端，记完即退回自由文本；四家有固定栏目的产品（格志、Five Minute Journal、Moo 日记、Reflection.app）字段清一色是情绪与感恩（mood / gratitude / highlights / lowlights）。把产出本身做成「目标—状态—投入—正反馈—反思」五栏、且其中三栏可被机器聚合的，0 家。这在日记品类里是唯一一处「字段层面」的空白，比功能层面的空位更难被抄——功能抄得走，字段口径抄不走，因为它连着复盘算法与成本结构。

一句对外口径（建议）： 不是“AI 帮你写日记”，而是“每天三分钟对话，把今天和你的长期目标连起来”。
划界句（不可删）： 判断与反思始终属于使用者本人，AI 只做启发与补全。
对内决策口径： 周期回顾本身已不空，真正空的是“低摩擦启动 + 目标对齐 + 参与度可调 + 免费给到一次完整循环”四块，再加产出端的固定五栏；其中“参与度可调”与“投入字段”目前 0 家在做。

十三 · 指标验证与结论标注体系

13.1 指标验证

北极星指标：每周完成至少 3 次有效记录，并查看周报的用户数。
辅助指标：AI 草稿修改率、周报查看率。其余为过程指标：次日 / 7 日 / 30 日留存、打开→对话→完成→保存→看周报的漏斗、主观有用度、付费意愿。
